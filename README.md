The Galaxy Tab S4 (codenamed _"gts4llte/gts4lwifi"_) is a high-end tablet from Samsung.

It was released in August 2018.

## Device specifications

Basic   | Spec Sheet
-------:|:-------------------------
CPU     | Octa-core (4x2.35 GHz Kryo & 4x1.9 GHz Kryo)
Chipset | Qualcomm MSM8998 Snapdragon 835
GPU     | Adreno 540
Memory  | 4/6 GB RAM
Shipped OS Version | Android 8.1 (Oreo)
Storage | 64/256 GB (UFS 2.1)
Battery | Non-removable Li-Po 7300 mAh
Display | 1600 x 2560 pixels, 10.5 inches, 16:10 ratio (~287 ppi density)
Camera  | 13MP (Primary), 8MP (Selfie), LED flash
